# Intro Build Calculator

A simple calculator project built as an introduction to software development.

## Overview

This repository contains the source code for a basic calculator. It is intended as a beginner-friendly project for practicing programming fundamentals.

## Features

- Perform basic arithmetic operations
- Simple and easy-to-understand project structure

## Getting Started

Clone the repository and follow the instructions for your project's language and build tools to run the calculator.
